ЯКБАЯК CHAT — LAN версия 0.4

ЧТО ДОБАВЛЕНО
- Общий чат и личные переписки один на один.
- Индикатор «печатает…».
- Отправка фото и файлов до 10 МБ.
- Отправка аудиофайлов и голосовых, если браузер поддерживает запись микрофона.
- Уведомления браузера, если браузер разрешает их для локального адреса.
- История хранится на ноутбуке в data/chat.json; вложения — в uploads/.

ЗАПУСК
1. Распакуйте архив.
2. Запустите START_SERVER_WINDOWS.bat.
3. На всех устройствах одной Wi-Fi сети откройте http://IP-НОУТБУКА:8765.
4. На каждом устройстве задайте уникальное имя и нажмите «Подключить».
5. Для личной переписки нажмите имя участника слева.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
- Это локальная версия: ноутбук должен быть включён, а все устройства — в одной Wi-Fi сети. Вне Wi-Fi синхронизации пока нет.
- Максимальный размер одного файла — 10 МБ.
- Уведомления браузера и запись микрофона зависят от браузера и его политики безопасности. На обычном HTTP-адресе вида http://192.168.x.x Chrome может блокировать уведомления/микрофон. Аудиофайл можно выбрать через 📎.
- Для постоянных уведомлений в фоне и надёжной записи голоса лучше отдельный Android APK с нативными разрешениями.
- Сервер не предназначен для выхода напрямую в интернет: нет TLS, паролей и шифрования. Не пробрасывайте порт 8765 в интернет.

ANDROID APK
Папка app/ — исходный проект Android Studio, не готовый APK. Для сборки нужен Android Studio/JDK/Gradle. В Windows 7 современные версии Android Studio и Android Gradle Plugin 8.x обычно не поддерживаются; поэтому собирать APK на этом ноутбуке может не получиться. Можно собрать проект на более новом компьютере.


=== ANDROID ПРОЕКТ v0.5 ===
Папка app содержит Android WebView-приложение. Минимальная версия Android: 6.0 (API 23).
В этой сборке исправлена передача разрешения микрофона из Android в WebView и добавлен системный выбор файлов.

ВАЖНО: это ИСХОДНЫЙ Android-проект, а не готовый APK. Для сборки нужен Android Studio/Android SDK и Gradle 8.9+ с JDK 17+. Windows 7 обычно не поддерживает актуальную Android Studio; для сборки APK лучше использовать более новый компьютер.

После установки APK пользователь вводит адрес работающего сервера (например, http://192.168.199.175:8765) в поле адреса внутри чата. Сервер на ноутбуке должен быть включён.

Локальная версия работает в одной Wi-Fi сети. Доступ из мобильного интернета и облачная синхронизация в этой сборке НЕ реализованы. Не публикуйте сервер напрямую в интернет: текущая LAN-версия не предназначена для открытого доступа.
