КАК ПОЛУЧИТЬ APK ЧЕРЕЗ ОБЛАЧНУЮ СБОРКУ

1. Создайте аккаунт GitHub (если его ещё нет).
2. Войдите на github.com и создайте новый пустой репозиторий, например YakbayakChat.
3. Загрузите в репозиторий ВСЕ файлы и папки из этой папки проекта
   (включая скрытую папку .github).
4. Откройте вкладку Actions.
5. Выберите workflow "Build Yakbayak CHAT APK".
6. Нажмите Run workflow и подтвердите запуск.
7. Дождитесь зелёной отметки успешной сборки.
8. Откройте завершённый запуск и скачайте artifact
   "Yakbayak-CHAT-debug-APK". Внутри будет app-debug.apk.

Важно:
- Это debug APK для тестирования, не публикационная подписанная сборка.
- Для работы с сервером в локальной сети телефон/планшет должен быть
  подключён к тому же Wi-Fi, что и ноутбук.
- APK пока является WebView-оболочкой существующего веб-чата.
  Уведомления при полностью закрытом приложении и облачная связь
  требуют отдельной реализации push-сервера и защищённого HTTPS.
- Не удаляйте рабочую папку сервера v0.4.2 и резервную копию data.
